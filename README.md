# ⚗️ ChemoSuite: Multimodal Chemometrics Platform

**ChemoSuite** — комплексная веб-платформа на Python + Streamlit для глубокого хемометрического анализа природного органического вещества (РОВ/NOM) и техногенного шлам-лигнина. Платформа объединяет масс-спектрометрию сверхвысокого разрешения (**FT-ICR MS**), спектроскопию трехмерных матриц возбуждения-испускания флуоресценции (**EEM-PARAFAC**) и методы мультиблочной интеграции данных (**Data Fusion + PLS-DA**).

Разработано в соответствии с методологией лаборатории природных гуминовых систем кафедры аналитической химии Химического факультета МГУ им. М.В. Ломоносова.

## 🔬 Аналитические модули

### 1. 🧪 NOM-Spectra FT-ICR MS Studio

Полнофункциональная среда обработки масс-спектров сверхвысокого разрешения:

* **Интерактивный Stick Plot:** высокопроизводительный рендеринг WebGL (Plotly) с автоматической аннотацией доминирующих пиков и экспортом графики высокого разрешения (SVG/PNG 300 DPI).


* **Внутренняя рекалибровка шкалы $m/z$:** полиномиальная коррекция систематического дрейфа прибора по реперным сериям жирных кислот ($C_{12}–C_{33}$) или гомологов $CHO$ с защитой от эффекта Рунге на краевых массах.


* **Приписывание брутто-формул:** векторный высокоскоростной генератор формул со стехиометрическими фильтрами ($H/C$, $O/C$, $DBE$, $DBE-O$), азотным правилом и изотопной валидацией по $^{13}\text{C}$ ($+1.00335$ Да).


* **Проекции химического пространства:**
* Диаграммы Ван-Кревелена ($H/C$ vs $O/C$) с дифференциацией по классам гетероатомов ($CHO$, $CHON$, $CHOS$, $CHONS$) и биохимическим пулам.


* Конденсированность $DBE$ vs $C$ с границами ароматичности и планарного предела Коха.


* Анализ дефекта массы Кендрика (**KMD**) по базовым группам $\text{CH}_2$, $\text{COO}$, $\text{O}$, $\text{H}_2$.




* **Хемотипирование по 20 ячейкам:** расчет матриц заселенности фазового пространства $H/C$–$O/C$ (методология проф. И.В. Перминовой) по относительному числу формул и средневзвешенной интенсивности.


* **Спектральная алгебра и парное сравнение:** зеркальные спектры (Head-to-Tail), попиковое вычитание холостой пробы (Blank Subtraction), диаграммы Венна и теоретико-множественные операции ($A \cap B$, $A \cup B$, $A \setminus B$, $A \oplus B$).


* **Скрининг реакционных сетей (TMDS):** таргетированный поиск характеристических биогеохимических трансформаций ($\Delta m$ с точностью до миллидальтон).

### 2. 💡 EEM-PARAFAC (3D Флуоресценция)

Модуль спектрофлуориметрии матриц возбуждения-испускания:

* **Предобработка оптических матриц:** автоматическое вырезание рэлеевского рассеяния 1-го порядка ($Em = Ex \pm 12$ нм) и 2-го порядка ($Em = 2Ex \pm 15$ нм) с двумерной интерполяцией методом Делоне.
* **Рамановская нормировка:** приведение интенсивностей к стандартным рамановским единицам (R.U.) по площади пика чистой воды ($Ex = 350$ нм).
* **Спектральные дескрипторы гумификации:**
* **FI (Fluorescence Index):** отношение $Em$ 470/520 нм при $Ex = 370$ нм (дифференциация автохтонного микробного и аллохтонного терригенного пулов).
* **HIX (Humification Index):** отношение интегралов эмиссии $\int_{435}^{480} / \int_{300}^{345}$ при $Ex = 254$ нм (степень конденсации ароматического каркаса).
* **$\text{SUVA}_{254}$:** удельное поглощение на 254 нм на единицу растворенного органического углерода (DOC).


* **Неотрицательное тензорное разложение PARAFAC:**
* Построение 3D-тензора: Образцы $\times$ Эмиссия ($Em$) $\times$ Возбуждение ($Ex$).
* Извлечение 3 независимых чистых компонентов:
* **C1:** автохтонный фульвоподобный флуорофор ($Ex \approx 250(320)$ нм, $Em \approx 405$ нм).
* **C2:** гуминоподобный полифенольный флуорофор шлам-лигнина ($Ex \approx 260(365)$ нм, $Em \approx 470$ нм).
* **C3:** белковоподобный / триптофановый автохтонный компонент ($Ex \approx 275$ нм, $Em \approx 340$ нм).


* Оценка стабильности факторизации по критерию **CORCONDIA** (Core Consistency Diagnostic) и доле объясненной дисперсии.

### 3. 🧬 ChemoSuite ML (Data Fusion & PLS-DA)

Кросс-модульная хемометрическая среда для задач таксономии и экологического мониторинга:

* **Low-Level Data Fusion:** низкоуровневая интеграция матриц признаков FT-ICR MS (векторы заселенности 20 ячеек, средневзвешенные $AI$, $DBE$) и оптических профилей EEM (индексы $FI$, $HIX$, $SUVA_{254}$, парциальные вклады $C_1–C_3$).
* **Блочное масштабирование (Block Scaling):** уравнивание статистического веса спектральных блоков с коэффициентом $1 / \sqrt{P_k}$ с последующей $Z$-score стандартизацией.
* **Классификатор PLS-DA:** проекция на ортогональные скрытые переменные ($LV_1$ vs $LV_2$) с построением 95% эллипса Хотеллинга ($T^2$) для детекции спектральных выбросов.
* **Кросс-валидация и валидация надежности:** расчет метрик объясненной дисперсии ($R^2X$, $R^2Y$), предсказательной способности ($Q^2$ по Leave-One-Out кросс-валидации) и точности классификации.
* **Идентификация маркеров (VIP Scores):** ранжирование дескрипторов по индексу значимости в проекции (Variable Importance in Projection). Переменные с $VIP > 1.0$ выделяются как ключевые маркеры техногенного воздействия шлам-лигнина.

## 📸 Скриншоты аналитических модулей и визуализации

### Модуль 1: Спектрометрия сверхвысокого разрешения (FT-ICR MS)

#### 1. Интерактивная диаграмма Ван-Кревелена (Van Krevelen Plot)

* **Назначение:** Картирование молекулярного состава органического вещества в координатах отношения элементов $H/C$ (степень насыщенности) против $O/C$ (степень окисленности)[cite: 8].
* **Химическая интерпретация:**
* Каждая точка соответствует идентифицированной брутто-формуле[cite: 8]. Точки автоматически сгруппированы по классам гетероатомов: преобладающий пул $CHO$ (5 604 формулы), азотсодержащие $CHON$ (307 формул) и серосодержащие $CHOS$ (30 формул)[cite: 8].
* График позволяет дифференцировать биохимические классы компонентов (липиды, белки, лигнины, углеводы и конденсированную ароматику)[cite: 1, 8].



#### 2. Анализ дефекта массы Кендрика (KMD Plot)

* **Назначение:** Выявление гомологических рядов и структурных паттернов по базовой функциональной единице (на примере $CH_2$)[cite: 7].
* **Химическая интерпретация:**
* Горизонтальные цепочки точек представляют собой гомологи, различающиеся на регулярное число повторяющихся звеньев $CH_2$ ($\Delta m = 14.01565$ Да) при неизменном числе гетероатомов и двойных связей[cite: 1, 7].
* Цветовая дифференциация по четности номинальной массы Кендрика (NKM Parity: четные — синий цвет, нечетные — оранжевый) наглядно разделяет соединения по правилу азота и позволяет детектировать радикальные ионы[cite: 7].



#### 3. Тепловая карта заселенности 20 ячеек Перминовой (20-Grid Density Heatmap)

* **Назначение:** Оцифровка непрерывного молекулярного пространства диаграммы Ван-Кревелена в дискретный 20-мерный вектор признаков ($VK_1–VK_{20}$) для статистического моделирования[cite: 1, 9].
* **Химическая интерпретация:**
* Фазовое пространство разбито на 5 диапазонов $H/C$ (R1–R5) и 4 диапазона $O/C$ (C1–C4)[cite: 9].
* Для исследуемого образца максимальная плотность формул сосредоточена в ячейках **$VK_{10}$ (24.7%)**, **$VK_6$ (15.4%)** и **$VK_{11}$ (14.5%)**, что соответствует термодинамически устойчивому полифенольному и лигниноподобному каркасу природного РОВ[cite: 9].

### Модуль 2: 3D Флуоресценция (EEM-PARAFAC)

#### 4. 2D Контурная карта флуоресценции (EEM Contour Map)

* **Назначение:** Интерактивная визуализация оптической матрицы возбуждения-испускания ($Ex$ 240–450 нм, $Em$ 280–600 нм) в цветовой шкале Viridis[cite: 6].
* **Особенности предобработки:** На карте отображены изолинии флуоресценции после автоматического устранения рэлеевского рассеяния 1-го и 2-го порядков методом локальной 2D-интерполяции Делоне[cite: 6]. Наблюдаются выраженные оптические центры в УФ- и видимой областях (гуминовые и лигноидные флуорофоры)[cite: 6].

#### 5. Спектральные профили компонентов PARAFAC (Loadings B & C)

* **Назначение:** Декомпозиция трехмерного массива EEM на спектры «чистых» химических компонентов: эмиссионные профили (Loading B) и профили возбуждения (Loading C)[cite: 5].
* **Хемометрическая валидация:**
* Модель объясняет **99.75%** общей дисперсии оптических матриц[cite: 5].
* Диагностический критерий **CORCONDIA = 99.2%** (статус *Model Valid*) подтверждает корректность выбора трехкомпонентного ранга без перепараметризации[cite: 5].
* Идентифицированы 3 ключевых флуорофора: **C1** (автохтонный фульвоподобный), **C2** (высококонденсированный гуминоподобный / лигнин) и **C3** (белковоподобный / триптофановый)[cite: 5].



#### 6. Концентрационные вклады флуорофоров по образцам (Scores Matrix A)

* **Назначение:** Сравнительный анализ относительного содержания компонентов C1, C2 и C3 в исследуемых сериях проб[cite: 4].
* **Химическая интерпретация:**
* Пробы зоны техногенного воздействия шлам-лигнина (`Lignin_Impact_1...5`) демонстрируют многократное преобладание оптических вкладов фульво- и лигниноподобных флуорофоров (C1 и C2) при практически полном подавлении белкового пула[cite: 4].
* Фоновые природные воды Байкала (`Baikal_Water_1...5`), напротив, характеризуются высокой долей автохтонной биогенной флуоресценции (компонент C3_Protein)[cite: 4].

### Модуль 3: Мультиблочная интеграция и машинное обучение (Data Fusion & PLS-DA)

#### 7. Дискриминантный анализ (PLS-DA) и отбор молекулярных маркеров (VIP Scores)

* **Назначение:** Мультимодальная классификация и выявление маркеров антропогенного загрязнения на основе объединения данных FT-ICR MS (векторы 20 ячеек, $AI$, $DBE$) и EEM-PARAFAC (индексы $FI$, $HIX$, $SUVA_{254}$, вклады $C_1–C_3$)[cite: 3].
* **Метрики качества модели:**
* $R^2X = 63.2\%$ (объясненная дисперсия спектральных блоков), $R^2Y = 100.0\%$ (разделение классов)[cite: 3].
* Внутренняя кросс-валидация Leave-One-Out подтверждает устойчивость модели: **$Q^2 = 97.7\%$** (порог надежности $>50\%$) при точности классификации **100.0%**[cite: 3].


* **Scores Plot ($t_1$ vs $t_2$):** Образцы шлам-лигнина (красные маркеры) и фоновых вод Байкала (синие маркеры) формируют изолированные компактные кластеры вдоль первой скрытой переменной ($LV_1$), находясь строго внутри 95% эллипса Хотеллинга ($T^2$) без выбросов[cite: 3].
* **VIP Scores (Key Markers):** Ранжирование признаков по значимости в проекции[cite: 3]. Главными маркерами техногенного лигнина выступают **C2_Lignin_Humic (VIP = 1.40)**, индекс флуоресценции **FI (VIP = 1.38)**, белковый пул **C3_Protein (VIP = 1.36)**, молекулярная ароматичность **AI (VIP = 1.36)** и ячейки высокой ненасыщенности **$VK_{15}$**, **$VK_9$**, **$VK_7$** ($VIP > 1.0$)[cite: 3].

## 🚀 Установка и запуск

### 1. Клонирование репозитория

```bash
git clone https://github.com/xav1c34/ChemoSuite.git
cd ChemoSuite

```

### 2. Развертывание виртуального окружения

**В среде Windows (PowerShell):**

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1

```

**В среде Linux / macOS:**

```bash
python3 -m venv .venv
source .venv/bin/activate

```

### 3. Установка зависимостей

```bash
pip install --upgrade pip
pip install -r requirements.txt

```

### 4. Запуск платформы

```bash
streamlit run app.py

```

Приложение откроется в браузере по адресу `http://localhost:8501`.

## 📦 Форматы входных данных

* **Масс-спектрометрия (FT-ICR MS):** текстовые файлы списков пиков (`.csv`, `.tsv`, `.txt`, `.xy`). Требуется минимум две числовые колонки: экспериментальная масса ($m/z$) и интенсивность/высота пика.


* **Флуориметрия (EEM):** 2D-таблицы матриц флуоресценции (`.csv`, `.dat`, `.txt`), где строки соответствуют длинам волн эмиссии ($Em$), а столбцы — возбуждения ($Ex$) (либо наоборот; парсер определяет ориентацию автоматически).
