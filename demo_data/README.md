# 🧪 ChemoSuite: Демонстрационный набор данных (Demo Data)

Комплексный согласованный эталонный набор спектральных данных для тестирования всех трех модулей платформы **ChemoSuite**.

Набор данных смоделирован на основе реальных физико-химических профилей кафедры аналитической химии и лаборатории природных гуминовых систем химфака МГУ:
1. **Зона техногенного воздействия (Шлам-лигнин БЦБК / Lignin Impact):** высокая ароматичность, низкий $H/C$, преобладание фульватных ($C_1$) и гуминовых ($C_2$) флуорофоров, выраженное плечо УФ-поглощения при 280 нм ($d^2A_{280} \ll 0$), низкое отношение $E_2/E_3$ и высокая расчетная молекулярная масса $M_w > 2000$ Да.
2. **Фоновый чистый Байкал (Baikal Control):** автохтонное природное РОВ, высокое соотношение $H/C$, повышенный вклад пептидных и алифатических соединений, доминирование белковоподобного флуорофора ($C_3$, триптофан/тирозин), высокое отношение $E_2/E_3$ ($> 4.5$) и низкая молекулярная масса $M_w < 1600$ Да.

## 🚀 Как использовать в приложении ChemoSuite

### 1. Модуль 1: FT-ICR MS Studio
* Загрузите файлы из папки `fticr_ms/` (например, `Lignin_Impact_01_fticr.csv` и `Baikal_Control_01_fticr.csv`).
* Нажмите **«Идентифицировать брутто-формулы»**, чтобы увидеть разделение пулов соединений на диаграмме Ван-Кревелена, серии KMD и тепловой карте 20 ячеек Перминовой.
* Протестируйте инструмент **«Спектральная алгебра»** ($A - B$) для выявления уникальных лигниновых маркеров.

### 2. Модуль 2: Оптическая спектроскопия (EEM & UV-Vis)
* **2D Флуоресценция:** загрузите файлы из `eem/` (рекомендуется выбрать 4–6 файлов). Включите галочку *«Удаление рэлеевского рассеяния»* и исследуйте разложение PARAFAC на 3 компонента.
* **1D Спектрофотометрия (Экран 4):** загрузите соответствующие файлы из `uv_vis/`. Программа автоматически рассчитает оптические индексы, оценит $M_w$ и определит лигниновый минимум 2-й производной $d^2A$ при 280 нм.

### 3. Модуль 3: ChemoSuite ML (Data Fusion & PLS-DA)
* **Вариант А (Единый файл):** в режиме *«Загрузка внешних CSV файлов»* выберите опцию *«Один общий файл с дескрипторами»* и укажите `multimodal_ml/chemo_unified_multimodal.csv`.
* **Вариант Б (Поблочная загрузка):** выберите опцию *«Отдельные файлы по блокам»* и загрузите соответствующие таблицы:
  * FT-ICR MS: `chemo_fticr_block.csv`
  * EEM-PARAFAC: `chemo_eem_block.csv`
  * UV-Vis: `chemo_uv_block.csv`
* Запустите модель PLS-DA и исследуйте графики Scores, VIP-маркеры, долю вклада аналитических блоков ($\text{VIP}^2$) и пермутационный тест валидации.
