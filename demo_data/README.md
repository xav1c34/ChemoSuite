# 🧪 ChemoSuite 3.0: Демонстрационный набор данных (Demo Data)

Комплексный согласованный эталонный набор спектральных данных для тестирования всех 8 модулей платформы **ChemoSuite 3.0**.

> ⚠️ **Данные синтетические.** Спектры и таблицы сгенерированы программно по типовым профилям и предназначены только для демонстрации и тестирования конвейеров (исключение — `fticr_ms/sample_A_full.csv`). Классы «Байкал» и «Шлам-лигнин» разделимы по построению, поэтому высокие Q², точность и VIP-маркеры на демо-наборе не являются научным результатом.
>
> *Synthetic data: generated for demonstration and pipeline testing only (except `fticr_ms/sample_A_full.csv`). The two classes are separable by construction, so model metrics on this set are not scientific evidence.*

Набор данных смоделирован на основе реальных физико-химических профилей кафедры аналитической химии и лаборатории природных гуминовых систем химфака МГУ:
1. **Зона техногенного воздействия (Шлам-лигнин БЦБК / Lignin Impact):** высокая ароматичность, низкий $H/C$, преобладание фульватных ($C_1$) и гуминовых ($C_2$) флуорофоров, выраженное плечо УФ-поглощения при 280 нм ($d^2A_{280} \ll 0$), низкое отношение $E_2/E_3$, высокое содержание серы ($S\% > 3\%$, лигносульфонаты), характерные полосы ароматического кольца FTIR (1510, 1595 см⁻¹), преобладание гваяцильных/сирингильных мономеров ЯМР/Py-GC-MS и повышенная полидисперсность SEC.
2. **Фоновый чистый Байкал (Baikal Control):** автохтонное природное РОВ, высокое соотношение $H/C$, низкое содержание серы ($S\% < 0.8\%$), доминирование белковоподобного флуорофора ($C_3$, триптофан/тирозин), высокое отношение $E_2/E_3$ ($> 4.5$) и низкая молекулярная масса $M_w < 1600$ Да.

## 🚀 Как использовать в ChemoSuite 3.0

1. **Автономный пакетный скрининг (Data Staging в Модуле 3):**
   * Выберите вкладку `⚡ Пакетный скрининг папок (Batch Screening)`.
   * Укажите директорию `demo_data` и нажмите **«Запустить автономный пакетный скрининг»**.
   * Платформа автоматически распознает все 8 аналитических методов, извлечет дескрипторы и сформирует единую матрицу `fused_df`.
   * Нажмите **«Использовать собранную матрицу в ChemoSuite ML»** для мгновенного перехода к классификации sPLS-DA/OPLS-DA, 2D-COS кросс-корреляционному атласу и экологическому паспорту.
2. **Модули 1–8:**
   * Открывайте файлы из соответствующих подкаталогов (`fticr_ms/`, `eem/`, `uv_vis/`, `ftir/`, `nmr/`, `thermal/`, `sec/`, `elemental/`) для подетального спектрального исследования и калибровки.
